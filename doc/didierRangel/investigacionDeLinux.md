# Investigacion sobre Linux

## Introduccion

Linux es un sistema operativo de código abierto basado en el kernel Linux, creado originalmente por Linus Torvalds en 1991. Con el paso del tiempo, Linux se convirtió en una de las principales tecnologías utilizadas en servidores, supercomputadoras, dispositivos electrónicos, servicios en la nube y computadoras personales.

## Historia de Linux

Linux comenzó como un proyecto personal de **Linus Torvalds**, quien en 1991 desarrolló un núcleo de sistema operativo inspirado en el funcionamiento de Unix. Su objetivo inicial era crear un sistema que pudiera utilizarse en computadoras personales.

El kernel fue publicado bajo una licencia que permitía estudiar, modificar y distribuir el código. Posteriormente, numerosos desarrolladores de todo el mundo contribuyeron al proyecto.

Es importante distinguir entre Linux y una distribución de Linux. Linux propiamente dicho es el núcleo que administra los recursos del computador, mientras que una distribución combina el kernel con programas, bibliotecas, herramientas y, normalmente, una interfaz gráfica.
