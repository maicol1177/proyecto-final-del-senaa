# Investigación sobre DartPad

## ¿Qué es DartPad?

**DartPad** es una herramienta en línea desarrollada por Google que permite **escribir, ejecutar y probar código Dart directamente desde un navegador web**, sin necesidad de instalar Dart en el computador.

Dart es el lenguaje de programación utilizado principalmente para desarrollar aplicaciones con **Flutter**.

## ¿Para qué se utiliza DartPad?

DartPad se utiliza principalmente para:

- **Aprender Dart:** practicar variables, funciones, clases y estructuras de control.
- **Probar código:** ejecutar pequeños programas rápidamente.
- **Aprender Flutter:** crear y probar interfaces gráficas.
- **Realizar demostraciones:** mostrar ejemplos de código.
- **Programar sin instalaciones:** funciona directamente desde el navegador.
- **Compartir código:** permite compartir ejemplos con otras personas.

## ¿Cómo se utiliza?

1. Ingresar a [DartPad](https://dartpad.dev/).
2. Seleccionar **Dart** o **Flutter**.
3. Escribir el código.
4. Ejecutar el programa.
5. Observar el resultado.
6. Corregir los errores y volver a ejecutar.

## Uso de DartPad

DartPad se utiliza para **escribir, ejecutar y probar código Dart y Flutter directamente desde un navegador web**, sin necesidad de instalar un entorno de desarrollo completo.

Sus principales usos son:

- Aprender el lenguaje de programación Dart.
- Practicar conceptos básicos de programación.
- Ejecutar y probar códigos pequeños.
- Identificar y corregir errores.
- Crear ejemplos de aplicaciones con Flutter.
- Realizar ejercicios y demostraciones educativas.
- Compartir código con otras personas.

## Modalidad de DartPad

DartPad funciona bajo una **modalidad en línea**, es decir, el código se escribe y ejecuta directamente desde un navegador.

Cuenta principalmente con dos modalidades:

### Modalidad Dart

Permite escribir y ejecutar programas utilizando el lenguaje **Dart**. Es ideal para aprender variables, funciones, ciclos, condicionales, clases y otros conceptos de programación.

### Modalidad Flutter

Permite crear y probar **interfaces gráficas y aplicaciones** utilizando Flutter. Es útil para aprender desarrollo de aplicaciones móviles y web.
