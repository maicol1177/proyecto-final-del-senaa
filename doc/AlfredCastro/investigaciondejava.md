JavaScript (abreviado JS) es el lenguaje de programación estándar de la web. Es el encargado de darle interactividad, dinamismo y comportamiento a las páginas web.
## para que sirve 
¿Para qué sirve?
En el desarrollo web, JavaScript trabaja junto con HTML y CSS:

HTML: Es la estructura y el contenido de la página (el "esqueleto").

CSS: Es el diseño y los estilos visuales (la "ropa" y la apariencia).

JavaScript: Es la lógica y la interactividad (el "cerebro" y los "músculos").

Sin JavaScript, una página web sería estática (como un documento de texto o una revista). Gracias a JavaScript, se pueden realizar acciones como:

Responder a clics, desplazamientos o teclas del usuario.

Mostrar animaciones, galerías de imágenes o desplegables.

Cargar o enviar información en segundo plano sin recargar toda la página (por ejemplo, al dar un "Me gusta" o enviar un mensaje).

Validar que un formulario esté bien completado antes de enviarlo.

Ejemplo sencillo de código
Así se ve un fragmento básico de JavaScript que muestra un mensaje cuando se hace un clic:

JavaScript
// Obtener un botón por su ID y asignarle un evento
const boton = document.getElementById("miBoton");

boton.addEventListener("click", function() {
  alert("¡Hola! Hiciste clic en el botón.");
});
## CUANDO FUE CREADO 
El Origen: Proyecto Green (1991)
El objetivo inicial no era crear un lenguaje para computadoras o páginas web. El equipo buscaba desarrollar tecnología para dispositivos electrónicos de consumo (como televisores interactivos, decodificadores de cable o electrodomésticos inteligentes).
